# 📋 LegalBot Colombia - Generador Inteligente de Contratos

## Descripción
LegalBot es una aplicación web inteligente que te ayuda a generar contratos legales personalizados en minutos. Perfecta para pequeñas empresas, emprendedores y profesionales independientes en Colombia.

## Características ✨

### 1. **Interfaz Amigable**
- Chat interactivo y fácil de usar
- Diseño responsivo para dispositivos móviles
- Visualización en tiempo real del contrato

### 2. **Tipos de Contratos Soportados**
- ⚖️ **Contrato de Arrendamiento** - Para inmuebles residenciales o comerciales
- 🤝 **Contrato de Servicios** - Para prestación de servicios profesionales
- 🔐 **Acuerdo de Confidencialidad** - Para proteger información sensible
- 💰 **Contrato de Compra-Venta** - Para transacciones de bienes
- 👔 **Contrato de Trabajo** - Para relaciones laborales

### 3. **Funcionalidades**
- ✅ Generación automática de contratos personalizados
- 📥 **Descargar** contratos en formato texto
- 📋 **Copiar** contrato al portapapeles
- 🗑️ **Limpiar** contrato para crear uno nuevo
- 💬 Chat interactivo para guiar el proceso

## 🚀 Cómo Usar

### Inicio Rápido
1. Abre `index.html` en tu navegador web
2. El bot te dará la bienvenida
3. Indica qué tipo de contrato necesitas
4. Proporciona la información requerida
5. El bot generará tu contrato automáticamente

### Ejemplo de Conversación

```
TÚ: Necesito un contrato de arrendamiento

BOT: Perfecto. Crearé un contrato de arrendamiento. Necesito:
- Nombre del arrendador
- Cédula del arrendador
- Descripción del inmueble
- Valor del arriendo
- Fecha de inicio
[... más información]

TÚ: Mi nombre es Juan García, cédula 1234567890, el apartamento está en la calle 5...
[Proporciona más detalles]

BOT: ✅ Contrato generado exitosamente.
```
